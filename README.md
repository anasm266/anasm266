## Selected work

- [**typing-race**](https://github.com/anasm266/typing-race) — real-time multiplayer typing races on Cloudflare Workers + Durable Objects: server-owned room state, reconnects, spectators, k6 load tests. [Live](https://typing-race.pages.dev) · [analytics](https://typing-race.pages.dev/analytics)
- [**any-map**](https://github.com/anasm266/any-map) — static flow analysis for TypeScript `any`: traces where it originates, ranks blast radius, gates PRs with SARIF. [npm](https://www.npmjs.com/package/any-map)
- [**installsentry**](https://github.com/anasm266/installsentry) — replays npm installs in a sandbox and records what lifecycle scripts actually did: file, network, and canary-secret access. [Threat model](https://github.com/anasm266/installsentry/blob/master/docs/THREAT-MODEL.md)
- [**apibump**](https://github.com/anasm266/apibump) — Rust CLI + GitHub Action for semantic public-API breakage checks in Python packages, dogfooded against forks of PyJWT and tomlkit. [crates.io](https://crates.io/crates/apibump)

More in the repos: [glint](https://github.com/anasm266/glint) (Rust/Tauri tray overlay for live AI coding sessions), [sentinelflow](https://github.com/anasm266/sentinelflow) (dependency-risk control plane), [appledger](https://github.com/anasm266/appledger) (Windows app activity attribution), [subsurface](https://github.com/anasm266/subsurface) (subtitle-intercepting Chrome extension).
